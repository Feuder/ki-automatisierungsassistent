# Ich schreibe hier meine Ideen für den weiteren verlauf des Programmes rein

## Ordnerverzeichnis
Es wird zuerst eine Kopie erstellt, mit einem Ordnerverzeichnis, wo die Dateien, erstmal als Name drinne stehe. Hier kann der User dann gucken, ob es ihm so gefällt oder nicht. Wenn nicht, soll er die Datein dort direkt verschieben können. 
Wenn der User das dann bestätigt, wird das Verzeichnis so erstellt und eingetragen
Wichtig hierbei ist es, das der Vorschlag immer wieder gelöscht wird und nicht permanent bleibt

## Dateien die zusammen gehören
Größere Verzeichnisse scannen zu können und Dopellte Verzeichnise erstellen und zu erkennen. 
Es soll einmal die klassische KI Vorgeschlagene Zuordnung kommen
Parallel soll aber auch noch nach verbindungen gesucht werden. Hierbei sollen Dateien die zum selben Thema gehören, z.b Präsentationsinhalt.docx und PowerPoint.pptx, in einem anderen Verzeichnis zusammen sein, damit man diese Dateien immer zusammenhat
Das kann man am besten in einer Verknüpfung machen, damit die Dateien immer den selben stand haben.
